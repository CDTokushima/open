# 周辺視野テスト v1.8.10

`index.html` を GitHub Pages のルートに配置します。

- 条件選択後、待機画面の「開始」ボタンまたは画面タップで測定開始。
- 最初の開始時のみ Web Speech API を起動し、測定間は採点を休止して認識セッションを維持。
- マイクを終了する専用ボタンを削除。ページを閉じる際にはセッションを終了。
- `。` / `.` / `句点` が音声認識テキスト中に現れた場合は「丸」の補正候補として採点し、元の認識テキストと補正情報を残す。
- `まる。` の末尾の句点は、すでに丸が認識されているため追加の丸として扱わない。

## 注意
自動挿入された句点と発話した「丸」を Web Speech API の文字列だけで完全に区別することはできません。句点による正解は**暫定的な補正候補**です。研究利用時は CSV の認識語・補正種別を確認してください。iOS の Web Speech API が自動終了した場合、再読み込みが必要になることがあります。
