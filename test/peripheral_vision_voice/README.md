# 周辺視野テスト v1.8.5

HTML/CSS/JavaScript 単体で動作するWeb Speech APIを用いた周辺視野テストです。GitHub Pagesでは `index.html` を公開してください。

## 回答語
- 上（うえ）＝北（きた）、右（みぎ）＝東（ひがし）、下（した）＝南（みなみ）・なみ・波、左（ひだり）＝西（にし）、丸（まる）。これらは正式な認識語です。
- 「ひなり→左」など、ひらがな読みの編集距離が1以下の語は補正候補として抽出します。既知の誤変換「稲荷→左」も候補です。
- ひらがなレベルで候補が複数同順位なら、方向を確定せず「要確認」とします。候補を選ぶ際には表示した正解を使いません。
- 未知の漢字の読みは外部の読み辞書なしには変換できません。対応済みの漢字表記は実装内の `directVocabulary` に列挙しています。
- 補正候補の正誤は暫定集計に含まれるため、研究分析では補正候補を除いた集計との感度分析を推奨します。CSVには認識原語、読み、編集距離、全候補を保存します。

## 実験条件
図形は各1.5秒×5回表示し、5図形の終了から2秒間の音声受付後に集計します。
反応時間は認識文字列が最初に現れた時刻に基づき、発話開始の厳密な測定値ではありません。

## v1.8.5 の変更
「なみ」「波」を「下」の方向別名として追加しました。読みの近さによる候補ではなく正式な認識語として処理し、元の認識文字列はCSVに残します。
