# 自転車ナビ・30m逸脱時自動再検索版

## 機能

- ページ表示直後にGPS追跡開始
- `watchPosition()` で現在位置を継続更新
- 走行に合わせて現在地マーカーを移動
- 自転車向けルート検索
- 表示中ルートから現在位置までの最短距離を随時計算
- **ルートから30mを超えて外れた場合だけ自動再検索**
- 再検索中の多重実行を防止
- 再検索後15秒間は再検索しないクールダウン
- 地図の現在位置追従 ON/OFF
- GPS精度円表示

## 自動再検索の条件

次の条件をすべて満たした場合だけ再検索します。

1. 目的地が設定されている
2. ルートがすでに表示されている
3. 現在位置からルートまでの最短距離が30mを超えている
4. 再検索処理中ではない
5. 前回の自動再検索から15秒以上経過している

## 距離判定

ルートは多数の線分から構成されています。
現在位置から各線分への最短距離を計算し、
その最小値を「ルートからの逸脱距離」としています。

30m程度の局所的な判定なので、
緯度経度をメートルへ変換した局所平面近似を使用しています。

## 注意

Safariを前面表示している間の利用を想定しています。
画面ロックやバックグラウンドでは位置更新が停止・抑制される場合があります。
