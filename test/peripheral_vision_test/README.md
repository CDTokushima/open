# 周辺視野テスト（Web版）

スマートフォン縦向き用の、HTML・CSS・JavaScriptのみで動作する刺激提示アプリです。
サーバー・外部ライブラリ・外部画像は不要です。

## 操作方法

1. 「(1) 基本」「(2) 大」「(3) 緑」「(4) 赤」「(5) 青」のいずれかを選択します。
2. 待機画面に選択した条件名が表示されます。
3. 画面をタッチすると、上・右・下・左・丸をランダムな順に1回ずつ、各1.5秒表示します。
4. 5図形の表示後に「終了」と表示されます。
5. 終了画面から同じ条件をやり直すか、条件選択へ戻れます。

図形の輪郭・カラーはユーザー提供の「周辺視野テスト.pdf」を元に作成しています。
PDFにおける「大」は、矢印全体の長さではなく、矢じり・軸の太さと丸の径を大きくしたものです。

## GitHub Pagesで公開

`index.html` をリポジトリのルートへ配置し、GitHubの **Settings → Pages → Deploy from a branch → main / (root)** を選びます。
公開URLをスマートフォンのブラウザで開くだけで使えます。
ローカルで `index.html` を直接開いても動作します。

## 実験時の注意

- 縦向きで表示してください。
- スマートフォンごとに画面サイズ、輝度、表示倍率、視距離が異なるため、被験者間比較では条件を揃えるか記録してください。
- 画面サイズに応じて図形を等比拡大・縮小します。
- 本版は刺激提示のみです。参加者の回答、正答率、反応時間、実験ログの取得は実装していません。
- ページが非表示になった場合、実行中の試行は中止され、待機画面に戻ります。
