# 周辺視野テスト（音声回答・反応時間測定）

スマートフォン縦向きで使用する、HTML / CSS / JavaScript のみのWebアプリです。GitHub Pagesで公開できます。外部ライブラリ・独自のサーバーは不要ですが、ブラウザが利用する音声認識サービスにはネットワーク接続が必要な場合があります。

## 公開方法

このフォルダの `index.html` をGitHubリポジトリ直下にアップロードし、Settings → Pages → Deploy from a branch → main / (root) を設定してください。GitHub PagesのHTTPS URLからアクセスしてください。音声認識の動作にはブラウザの対応とマイク使用の許可が必要です。

## 操作方法

1. 条件（基本・大・緑・赤・青）を選択します。
2. 待機画面でタップし、マイクの使用を許可します。
3. 音声認識が開始されてから、上・右・下・左・丸が無作為な順番で1回ずつ、各1.5秒表示されます。
4. 表示中に「上」「右」「下」「左」「丸」のいずれかを1語ずつ、はっきり発声します。
5. 5つ目の表示が終わった後、音声認識の最終結果を約2.3秒待って集計します。
6. 結果画面では正解数と、不正解・未回答・認識不能の件数、各試行の表示刺激、回答、判定、反応時間を確認できます。CSVで保存できます。

## 正誤・時間計測のルール

- **正解：** ブラウザで認識した回答が、その表示の図形と一致した場合。
- **不正解：** 音声認識結果が5種類の図形のいずれかで、表示中の図形と異なる場合。
- **認識不能：** 発話を検知しても、五つの回答に対応づけられる語を認識できなかった場合。
- **未回答：** 発話イベントも回答の認識も得られなかった場合。これらは不正解から区別します。
- **反応時間：** 図形を描画する際の `performance.now()` と、`SpeechRecognition.onspeechstart` のコールバック受信時刻の差（ms）を表示します。`onspeechstart` が得られなかった場合は `onresult` のコールバック受信時刻を代用し、その値に「※」を付けます。
- 各表示中に開始された発話のうち、対応する**最初の認識結果**を採用します。発話が1.5秒内に開始されても、認識結果は後から届く場合があるので、可能な限り発話検知イベントの発生時刻で刺激と回答を結びつけています。
- 図形の提示時刻はJavaScriptのDOM更新時刻です。画面の実際の発光開始時刻との間にはブラウザ描画の時間差があり、また音声検知イベントにも内部処理による遅延があります。**反応時間は厳密な発声開始時刻ではなく概算値です。**
- 一つの長い発話として複数語が結合される場合、5試行への正確な分離は保証されません。単語ごとに短く区切って回答してください。
- 音声認識が途中で停止・エラーになった場合、測定を無効として待機画面に戻ります（誤った成績は表示しません）。

## CSV項目

日時（ISO8601）、条件、試行、表示、認識された回答、認識原文、判定、反応時間（ms）、計測基準。

結果は端末上で処理・保存します。アプリから独自サーバーに送信する機能はありませんが、音声認識エンジン自体が音声を外部サービスに送る可能性があります。参加者に明示してください。

## ブラウザと実験上の注意

- `SpeechRecognition` / `webkitSpeechRecognition` に対応したブラウザが必要です。iPhoneのSafariやAndroidのChrome等でも、OS・バージョン・設定・音声認識サービスの状態によって動作は異なります。実験実施端末で事前に検証してください。
- GitHub Pages（HTTPS）上での利用を推奨します。`file://` のローカル閲覧では音声認識が動作しない場合があります。
- 反応時間、判定、未回答率にはマイク、ブラウザ、通信状況、周囲の騒音が影響します。厳密な被験者間比較には端末・環境・音声認識方式の統制が重要です。
- 縦向きで使用し、画面サイズ・画面輝度・表示倍率・被験者からの距離などの条件を揃えるか記録してください。

## 図形について

ユーザー提供「周辺視野テスト.pdf」の矢印と丸をベースにしています。上向き矢印を90°単位で回転して4方向を生成します。全方向で矢印の全長が412.66 SVG単位で完全一致します。大条件は全長は変えず、矢印の幅・矢じりと丸の径を大きくしています。
