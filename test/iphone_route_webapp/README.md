# 自転車ナビ v2.0 — 周辺視野・赤色全画面矢印

## 画面の動作

- ページ表示直後からGPS取得、停止中は従来の地図画面。
- 目的地を地図でタップ→「自転車ルート」を押し、自転車ルートを検索。
- 走行速度が **1.2m/s（約4.3km/h）以上** になると全画面の白背景＋大きな赤矢印へ切替。
- **0.6m/s（約2.2km/h）以下が約3秒間続くと** 地図画面に復帰。GPS更新が12秒以上途絶えた場合も安全側で復帰。
- 曲がる方向は**iPhone上端が向く方向を0°とする相対方向**。上、右、下、左の4方向。
- ルートの約20〜40m先の方位を使用。交差点が約30〜45m以内ならルート案内の曲がった後の方向を優先。
- 矢印は単に目的地の直線方向ではなく、ルート沿いの方向を表示。
- GPS位置精度が40mより悪いときは新規の移動判定を保留。

## iPhoneの方位センサー権限

最初に停止した状態で「🧭 方位センサーを有効にする」を押して許可してください。
「自転車ルート」のタップでも許可を要求します。Safariでは方位情報の取得にユーザー操作による許可が必要な場合があります。

端末方位が取得できない場合は、GPSの進行方位にフォールバックします。その場合は
「GPSの進行方位を基準に案内（端末方位ではありません）」と表示します。GPSの進行方位も不明な場合は赤矢印を隠して「方位を取得中」と表示します。

iPhoneの上端を進行方向に向け、**縦向きで画面が見える状態**を想定しています。方位センサーは金属製ハンドルや磁石等の影響を受ける場合があります。

## 従来機能

- スクリーンWake Lock（対応ブラウザのみ）
- 現在地の継続取得、地図中央追従
- 自転車ルート（OSRM公開サービス）
- 30m以上逸脱時の再ルート検索（15秒クールダウン）
- 20m以内のゴール！＋紙吹雪。ゴール表示はタップするまで消えない。
- 縦向き専用。横向きでは「縦向きにしてください」表示。

## ファイル

`index.html`, `style.css`, `nav-core.js`, `app.js`, `manifest.webmanifest`

GitHub Pagesの公開ディレクトリに5ファイルを上書き／追加してください。以前の `sw.js` を登録した版を使っていた場合は、Service Workerとキャッシュが古いページを保持することがあります。更新されないときはiPhoneのSafariのサイトデータを削除するか、過去のPWAを削除して再登録してください。

## 動作確認

`node tests/test-navigation.js` でルート方位・4方向・距離計算・GPS速度補完を検証できます。
実機の方位権限とGPSの動作はiPhone Safari上で確認してください。

**注意:** Safari表示中だけの追跡です。バックグラウンドGPSには対応しません。自転車走行時の安全確保を優先し、実験はまず停止・安全な環境で行ってください。矢印はGPS精度・地図経路データの影響を受けます。
