# 自転車ナビ・横向き/PWA対応版

縦向き:
- 従来どおり地図が上部
- ボタンが画面下部

横向き:
- 地図を画面高いっぱいに表示
- ボタンを右側へ縦配置
- 状態表示は地図左上に半透明表示
- 地図の上下が画面内に収まるよう調整

iPhoneでSafariのタブやアドレスバーを消したい場合:
1. Safariで開く
2. 共有
3. 「ホーム画面に追加」
4. 追加したアイコンから起動

通常のSafariページからタブバーを強制的に消すことはできません。
この版はPWA対応済みで、ホーム画面から起動するとstandalone表示になります。
