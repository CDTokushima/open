# 自転車ルート版 かんたんルートナビ

変更点:
- ページ表示直後に現在地を自動取得
- ルート検索を自転車向けに変更
- 自転車ルートには routing.openstreetmap.de の `routed-bike` を使用
- 地図タイル崩れ対策を維持

## 動作
1. ページ表示
2. 自動的に現在地取得
3. 地図上で目的地をタップ
4. 「自転車ルートを検索」
5. 自転車向けルートを地図上に表示

## 注意
位置情報は HTTPS または localhost で利用してください。

`routing.openstreetmap.de` は公開ルーティングサービスです。
試作・学習用途には便利ですが、本番運用や大量アクセスでは
専用APIや自前サーバーの利用を検討してください。

Apple Mapsの「案内」ボタンは現状徒歩指定のままです。
Apple Maps URL では自転車モードの利用可否が地域・端末側仕様に依存するため、
Web画面内のルート検索を自転車向けにしています。
