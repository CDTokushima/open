# 周辺視野テスト v1.8.6

## 公開
`index.html` を GitHub Pages のリポジトリ直下へ配置してください。

## v1.8.6 変更点
Web Speech API の暫定認識結果に含まれる重複語（例：`南東` → `南東東北` → `南東北丸西`）を、最終確定テキストに5語の明確な回答がある場合、重複計上しないよう変更しました。最終確定テキストを回答順の基準とし、各語の最初の暫定出現時刻を文字列更新ログから対応付けます。

最終確定結果が5語揃わないときには従来の時間推定による部分対応付けを使用します。この場合の正誤・対応関係は推定です。

## 注意
初出時刻は文字列がWeb Speech APIから初めて通知された時刻で、実際の発話開始時刻ではありません。文全体の確定時に後から単語が挿入されると、その単語の初出時刻は実際の発話開始より遅くなります。発話開始推定時間は一定遅延を仮定した参考値です。CSVにログを残してください。
