# 周辺視野テスト v1.8.9 — 音声認識継続方式

スマートフォン縦向きの周辺視野テスト。HTML/CSS/JavaScriptのみを使用し、GitHub Pagesに `index.html` を配置するだけで利用できます。

## 使用手順

1. 基本・大・緑・赤・青のいずれかを選択します。
2. 画面をタッチすると、最初の測定だけ `SpeechRecognition.start()` を呼びます。事前のテスト発話は不要です。
3. 上・右・下・左・丸を、各1.5秒間隔でランダム順に1回ずつ表示します。北・東・南・西などにも対応します。
4. 最終図形表示の終了後、追加の2秒間は回答を受け付け、結果を表示します。
5. 結果画面では **採点をOFF** にしますが、マイクと音声認識は動作を継続します。
6. 「同じ条件でもう一度」で前回の音声認識インスタンスを **停止・再起動せず再利用** します。条件選択に戻っても、認識が動いていれば引き続き再利用できます。
7. 「マイクを終了」を押した場合は `stop()` で音声認識を停止します。以後の新規測定にはページ再読み込みが必要です。

## 主な設計変更

- 測定ごとの `stop()` → `start()` を廃止し、測定中の採点だけON、それ以外は採点OFFにしました。
- 測定前から存在する `SpeechRecognition` の認識結果は採点しません。認識結果のインデックスと、テキストの前回測定からの差分を参照します。
- マイクの状態を画面上に表示し、明示的に停止できるようにしました。
- 音声認識がブラウザ側で自動終了した場合は再利用せず、再読み込みが必要な旨を表示します。
- 新たなマイク取得との干渉を避けるため、v1.8.7にあった別系統の `getUserMedia()` による手動マイク確認ボタンは除外しました。
- 従来の語彙・正誤・反応時間・CSV・認識ログ機能は維持しています。

## 注意点

- **採点OFFは録音OFFではありません。** 結果画面や条件選択画面でもマイクは有効のままです。使用を終える際は「マイクを終了」を押してください。
- Web Speech APIの `continuous=true` は音声認識セッションの継続を保証しません。とくにiPhone/iOSでは沈黙やブラウザの状態によって認識が自動終了することがあります。自動終了時は、次の測定前にページの再読み込みが必要です。
- 認識エンジンが過去の語を大きく書き換えた場合、発話と表示の対応に不確実性が生じます。
- 初出反応時間には認識エンジンの遅延が含まれます。発話開始時刻そのものの実測値ではありません。
- サイトをHTTPSで公開して使用してください。
- 端末の実マイクでの再現性は検証していません。JavaScriptの構文確認、および模擬音声認識での2回連続測定・認識テキスト連結・自動終了・手動停止を確認しました。
