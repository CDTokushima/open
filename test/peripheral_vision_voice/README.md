# 周辺視野テスト — v1.8.7 再初期化版

HTML + JavaScriptの単一ファイル版です。既存の v1.8.7 を基に、再測定時の音声認識リソースの解放と新規読み込みを追加しました。**v1.8.8の事前音声確認（「テスト」と発話）は含みません。**

## GitHub Pagesへの設置

`index.html` を公開リポジトリのルートに置き、GitHub Pagesを有効にしてください。`https://` のサイトで利用します。

## 測定の流れ

1. 「基本」「大」「緑」「赤」「青」から選択。
2. 待機画面をタッチすると音声認識を開始。事前発話は不要。
3. 上・右・下・左・丸をランダム順に1.5秒ずつ表示。
4. 最後の図形の表示が終わったあと、さらに2秒間、音声認識を続けてから集計。
5. 必要ならCSVを保存。

## 再測定の変更点

- 「同じ条件でもう一度」では、前回の認識インスタンス・イベントハンドラ・タイマー・記録などを参照から外し、URLに新しい識別子を付けて**別のドキュメントとして読み込み直します**。
- 正常に`end`で終了した音声認識に対して、追加の`abort()`は呼びません。認識がまだ実行中の場合に限り強制停止し、`end`を確認（届かない場合はタイムアウト処理）してから再読み込みします。
- 「条件選択に戻る」と、復旧用の再読み込みボタンも同様に新しいドキュメントを読み込みます。
- マイク権限確認で取得したMediaStreamのトラックは直ちに停止します。ページ遷移時に残存トラックがあれば停止します。
- 新しいページでは選択していた条件の待機画面まで復元します。タッチ時に`new SpeechRecognition()`で新規インスタンスを作成します。
- iPhoneの戻る操作などで古いドキュメントがbfcacheから復元された場合もページを再読み込みします。

## 技術的な制約

JavaScriptからブラウザ内部（WebKit/iOS）の音声認識サービスそのものの破棄や、ガベージコレクションを強制することはできません。本変更は**アプリが持つ参照・タイマー・マイク取得ストリームの解放、および新規ページの読み込み**に限定されます。実機で2回目も音声が取れない場合は、Safari側の制約・不具合が残る可能性があります。

Web Speech APIの一時的な認識結果には遅延や書き換えがあるため、初出反応時間は厳密な発話開始時刻ではありません。

## 変更していない機能

v1.8.7と同じ刺激形状、色、矢印の縦横長、5図形、ランダム表示、認識語の補正、東西南北への対応、1.5秒間隔、終了後2秒の受付、結果表示、CSV出力を維持しています。
