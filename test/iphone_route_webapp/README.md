# 自転車ナビ（縦向き専用・作り直し版）

ゼロから組み直した版です。

## 主な機能

- ページ表示直後に現在位置を自動取得
- `navigator.geolocation.watchPosition()` で現在位置を継続更新
- 自転車走行に合わせて現在地マーカーを移動
- GPS精度を円で表示
- 地図タップで目的地設定
- 自転車向けルート検索
- ルートから30m以上外れた場合のみ自動再検索
- 再検索後15秒は再検索しない
- 目的地から20m以内で「ゴール！」
- 紙吹雪アニメーション
- 可能な場合はクラッカー風サウンド
- ゴール後は自動再検索を停止
- 縦向きでは地図上部、ボタン下部
- 横向きでは「縦向きにしてください」と全面表示

## PWA

`manifest.webmanifest` の

```json
"orientation": "portrait"
```

により、ホーム画面に追加してPWAとして起動した場合は
縦向き固定を要求します。

通常のSafariタブとして開いた場合、iOS側の回転そのものを
Webページから完全禁止することはできません。
そのため横向きでは操作画面を隠し、
「縦向きにしてください」と表示します。

## GitHub Pagesにアップロードするファイル

- `index.html`
- `style.css`
- `app.js`
- `manifest.webmanifest`

## 注意

位置情報APIはHTTPS環境が必要です。
GitHub PagesならHTTPSなので利用できます。

自転車ルートは `routing.openstreetmap.de` の公開ルーティングサービスを使っています。
試作・学習用途向けです。

## ゴール表示

ゴール表示は自動では消えません。画面をタップすると閉じます。

## 現在位置追従

- 通常は「追従：ON」
- GPS更新のたびに現在位置を地図中央へ移動
- 自転車が進むと、現在位置マーカーは中央付近に保たれ、地図がスクロール
- ルート検索後も追従ONを維持
- 自動再検索後も追従ONを維持
- 地図を手動でドラッグすると追従OFF
- 「追従：ON」を押すと現在位置中央追従に戻る
